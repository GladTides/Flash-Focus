Flash Focus – Complete Game Development Prompt
Create a polished, production-quality browser game called Flash Focus using HTML, CSS, and JavaScript in a single self-contained file. The game must run smoothly on modern desktop browsers without external libraries, frameworks, or internet access.
Core Concept
Flash Focus is a single-player attention and reaction game based on the classic Stroop Effect.
The player must identify the COLOR they see, not the word they read.
The experience should feel like a fast-paced arcade game mixed with a light cognitive-training challenge.
Visual Design
Design for a 16:9 desktop monitor.
Requirements:
Large, bold typography readable from several meters away.
Bright, vivid color palette.
Clean modern UI.
High contrast and accessibility-friendly.
Smooth animations and transitions.
Responsive layout that scales across desktop resolutions.
Professional and fun visual style.
