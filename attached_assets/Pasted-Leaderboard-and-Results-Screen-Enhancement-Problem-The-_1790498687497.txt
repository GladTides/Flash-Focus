Leaderboard and Results Screen Enhancement

Problem

The leaderboard currently allows the same participant to occupy multiple ranks.

Example:

#1 Mubashshir 01 855
#2 Mubashshir 01 759
#3 Mubashshir 01 659
#4 Mubashshir 01 616

This is incorrect.

The leaderboard must rank participants, not individual game sessions.

====================================================
LEADERBOARD FIX
====================================================

Requirements:

1. A participant may occupy only ONE leaderboard position.

2. Keep only the participant's BEST score for the active competition.

3. If a participant plays again:

   - Lower score:
     Do not change the leaderboard entry.

   - Higher score:
     Update the existing leaderboard entry.

4. Preserve existing tie-break order:

   - Best streak
   - Accuracy
   - Lower average reaction time

5. Verify:

   - One participant cannot appear multiple times.
   - Top 10 contains unique participants.
   - Existing duplicate leaderboard rows are consolidated into the participant's best result.

6. Fix the ROOT CAUSE.

Investigate:

   - leaderboard query
   - leaderboard_entries table constraints
   - participant identity logic
   - score-submission flow

Do not hide duplicates purely in the UI.
Fix the underlying data or query logic.
